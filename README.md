# Trackify - Lost & Found Management System

Trackify is a web-based Lost & Found Management System designed to simplify the process of reporting, searching, and claiming lost items. The platform provides an organized way for users to post lost or found items while allowing administrators to manage and verify submissions.

## 🚀 Features

- User Registration & Login
- Secure Authentication
- Report Lost Items
- Report Found Items
- Search and Browse Items
- Item Details Page
- Admin Dashboard
- Manage Users and Posts
- Responsive User Interface
- Simple and Easy Navigation

## ⚙️ Installation

1. Clone the repository

```
git clone https://github.com/your-username/Trackify-Lost-and-Found-System.git
```

2. Move the project folder to your XAMPP `htdocs` directory.

3. Start Apache and MySQL from XAMPP.

4. Import the SQL database into phpMyAdmin.

5. Update database credentials if required.

6. Open your browser and visit:

```
http://localhost/Trackify-Lost-and-Found-System/
```
